<h1>The Dicee App - A randomised dice rolling app</h1>
<p>This is a project for the Dicee app in which I learned about core programming concepts through Udemy</p>
<h3>What I learnt with this project:</h3> 
<li>
  How to clone an existing Xcode project from GitHub.</li>
  <li>Create an app with behaviour and functionality.</li>
  <li>Create links between the Interface Builder files and code using IBActions and IBOutlets.</li>
  <li>Get familiar with the Xcode code editor.</li>
  <li>Learn to use comments to annotate code.</li>
  <li>Understand and use Swift constants and variables.</li>
  <li>Understand and use collection types such as Swift arrays.</li>
  <li>Test and debug your app with the Xcode console.</li>
  <li>Learn about randomisation and how to generate random numbers in Swift.</li>
